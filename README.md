Personal Expense Tracker

Project Description

The Personal Expense Tracker is a beginner-friendly Python mini project that helps users record and manage their daily expenses. It allows users to calculate total spending, track expenses by category, and check their budget.

Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- View category-wise spending
- Check budget and remaining balance
- Delete an expense
- Save expense data in a CSV file
- Handle invalid user input

Technologies Used

- Python 3
- CSV module
- OS module
- Collections module

Python Concepts Used

- Variables and data types
- Lists and dictionaries
- Functions
- Loops
- Conditional statements
- Exception handling
- File handling
- CSV data storage

How to Run

1. Install Python 3 on your computer.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run the following command:
   
   "python expense_tracker.py"

5. Follow the menu displayed in the terminal.

Example

If you add the following expenses:

Category| Amount
Food| ₹150
Travel| ₹80
Shopping| ₹200
Total| ₹430

The program calculates total spending and shows the amount remaining from your budget.

Project Purpose

This project was created as part of a beginner Python learning module to practise programming fundamentals through a real-life application.
